# 영어 워크북 메이커

영어 지문으로 어휘·해석·어법·빈칸·배열·영작 활동이 담긴 **워크북**을 만들고, **한글 파일** 또는 **PDF**로 저장하는 웹 프로그램입니다. 설치할 것은 없습니다.

## 쓰는 방법

1. `index.html` 파일 하나를 내려받아 더블클릭하면 브라우저(크롬, 엣지)에서 열립니다.
2. **지문 보관함**에서 교재를 만들고 지문을 번호별로 등록합니다. 같은 브라우저에서 파일로 열면 [변형문제 메이커](../variant-maker/)와 **같은 보관함**을 씁니다. 변형문제 메이커에서 저장한 보관함 파일(.json)도 그대로 불러올 수 있습니다.
3. **워크북에 넣을 지문 고르기**에서 지문을 체크합니다. 여러 교재를 섞어도 됩니다.
4. **활동 고르기**에서 넣을 활동을 체크하고 **워크북 만들기**를 누릅니다. 다시 누르면 빈칸 위치·섞는 순서가 새로 바뀐 워크북이 나옵니다(같은 반에 A형·B형을 낼 때 쓰세요).
5. 오른쪽 쪽 미리보기에서 필요 없는 활동을 지울 수 있습니다. **묶는 방식**으로 지문별(29번: 활동 1~11 → 30번: …)이나 활동별(어휘 정리: 29번, 30번 → 빈칸 채우기: …)을 고릅니다. **묶음마다 새 쪽**을 켜면 지문(또는 활동)마다 새 쪽에서 시작합니다.
6. **워크북 꾸미기**에서 제목, 머리말, 꼬리말을 넣고 **한글 파일 저장** 또는 **PDF 저장**을 누릅니다.
   - `index.html` 파일로 열면 `.hwpx`로 저장됩니다.
   - Claude 화면 안에서는 `.docx`로 저장됩니다. 한글에서 바로 열리고, [파일 → 다른 이름으로 저장]에서 HWP로 바꿀 수 있습니다.

## 활동

| 방식 | 활동 | 워크북에 실리는 모양 | 정답지 |
|---|---|---|---|
| 자동 | 본문 읽기 | 문장마다 ①②③ 번호를 붙인 본문 | - |
| AI | 문장별 해석 | 영어 문장 아래 우리말 해석 | - |
| AI | 어휘 정리 | 번호·단어·품사·뜻 표 (12~16개) | - |
| AI | 어휘 테스트 | 앞쪽 절반은 영어 → 뜻, 뒤쪽 절반은 뜻 → 영어를 쓰는 표 | 뜻·단어 |
| AI | 어법 선택 | 본문 속 `(1) [were / was]` 고르기 6~8개 | 정답 + 출제 포인트 |
| AI | 어휘 선택 | 본문 속 `(1) [rare / common]` 문맥 고르기 5~7개 | 정답 + 근거 |
| 자동 | 빈칸 채우기 | 핵심 낱말을 `(1) c__________`처럼 첫 글자만 남기고 비움 | 낱말 |
| 자동 | 문장 순서 배열 | 첫 문장을 주고 나머지를 (A)~(H)로 섞음 | 순서 |
| 자동 | 단어 배열 | 문장마다 낱말(긴 문장은 2~3낱말 덩어리)을 `/`로 섞음 | 문장 |
| AI | 해석 쓰기 | 영어 문장 + 쓰는 줄(긴 문장은 두 줄) | 해석 |
| AI | 영작하기 | 우리말 해석 + 쓰는 줄 | 영어 문장 |

- 자동 활동은 무료로 바로 만들어집니다.
- AI 활동은 Claude가 지문마다 **해석·어휘·어법·어휘 선택 자료**를 한 번 만들어 두고, 워크북을 다시 만들 때는 그 자료를 그대로 씁니다(사용량을 다시 쓰지 않습니다). 고른 활동에 필요한 항목만 요청합니다.
- AI 자료가 있으면 자동 활동도 더 좋아집니다: 빈칸 채우기는 어휘 정리의 낱말을 먼저 빈칸으로 만들고, 단어 배열은 문장마다 우리말 뜻을 함께 보여 줍니다.
- 처음 열면 예시 지문(29번)에 AI 자료가 미리 들어 있어 AI 활동이 어떻게 나오는지 바로 볼 수 있습니다.

AI 자료를 만드는 방법은 두 가지입니다.

- **Claude 화면 안에서 열었을 때**: 버튼을 누르면 Claude가 바로 만듭니다. 사용하는 사람의 Claude 사용량을 씁니다.
- **파일로 열었을 때**: AI 활동은 빠진 채로 워크북을 먼저 만들고, 요청문을 보여 줍니다. 요청문을 복사해 [claude.ai](https://claude.ai/new) 채팅에 붙여 넣고, 답변을 다시 붙여 넣어 **불러오기**를 누르면 AI 활동을 넣어 워크북을 다시 짭니다.

## 검사

프로그램이 AI 자료를 그대로 믿지 않고 확인합니다.

- 해석 개수가 문장 수와 다르면 알려 주고 빠진 해석은 비워 둡니다.
- 어법·어휘 선택의 정답 낱말이 지문에 글자 그대로 없으면 그 항목을 빼고 알려 줍니다. 문장 번호가 틀렸으면 그 낱말이 있는 문장으로 옮깁니다.
- 어휘의 `지문 속 형태`가 지문에 없으면 빈칸 채우기에 쓰지 않습니다.

AI가 만든 해석·어휘·어법 자료는 반드시 검토한 뒤 사용하세요.

## 개발

변형문제 메이커의 `core.js`(문장 나누기, 지문 번호, 한글·Word 파일 만들기)와 `style.css`, `hwpx-template.js`를 함께 씁니다. `src/`를 고친 뒤 하나로 합칩니다.

```bash
python workbook-maker/build.py
```

```bash
node --test workbook-maker/tests/wb-core.test.js
```
