# 영어 변형문제 메이커

영어 지문 하나로 수능·모의고사 유형의 변형문제를 만들고, 문제지와 정답지를 **한글 파일** 또는 **PDF**로 저장하는 웹 프로그램입니다. 설치할 것은 없습니다.

## 쓰는 방법

1. `index.html` 파일 하나를 내려받아 더블클릭하면 브라우저(크롬, 엣지)에서 열립니다.
2. **지문 보관함**에서 교재(예: `26년 9월 고2 모의고사`, `수능특강 영어`)를 만들고, 그 아래에 지문을 번호별로 등록합니다. 번호는 `29`, `41-42`, `3강 1번`처럼 자유롭게 쓸 수 있고, 여러 지문은 `[18]`, `19번`, `[3강 1번]` 같은 번호 줄을 넣어 한꺼번에 붙여 넣을 수 있습니다.
3. **문제지에 넣을 지문 고르기**에서 모든 교재의 지문 중 원하는 것을 체크합니다. 여러 교재를 섞어도 됩니다. 그다음 유형과 지문당 개수(1~5)를 정합니다.
4. **문제 만들기**를 누릅니다. 문제는 유형별로 묶여 주장 → 요지 → 주제 → 제목 → 함축적 의미 → 어법 → 어휘 → 빈칸 → 순서 → 문장삽입 → 요약 → 어법 오류 고치기 → 서술형 문장배열 → 한글 문장 영작 순서로 실리고, 같은 유형 안에서는 지문 순서대로 놓입니다. 한 지문에서 같은 유형을 2개 이상 만들면 유형 안에서 1회차(모든 지문의 첫 번째 문제), 2회차(두 번째 문제) 순서로 번갈아 나오고, **회차별로 나누기**를 켜면 1회차 시험지와 2회차 시험지로 쪽을 나눠 번호를 1부터 다시 매깁니다. 발문 위에는 원문 번호(예: `29번`, 여러 교재를 섞으면 `26년 9월 · 29번`)가 표시됩니다. 정답지에는 정답과 해설만 나옵니다.
5. **문제지 꾸미기**에서 제목, 머리말(왼쪽·오른쪽), 꼬리말(왼쪽·오른쪽)을 입력합니다. 쪽 번호는 꼬리말 가운데에 자동으로 들어갑니다.
6. 오른쪽 쪽 미리보기에서 필요 없는 문제를 지울 수 있습니다. 문제 순서는 늘 자동으로 맞춰집니다.
7. **한글 파일 저장** 또는 **PDF 저장**을 누릅니다.
   - `index.html` 파일로 열면 `.hwpx`로 저장됩니다.
   - Claude 화면 안에서는 `.hwpx` 저장이 막혀 있어 `.docx`로 저장됩니다. 한글에서 바로 열리고, [파일 → 다른 이름으로 저장]에서 HWP·HWPX로 바꿀 수 있습니다.

## 유형

| 방식 | 유형 | 설명 |
|---|---|---|
| 자동 (무료) | 순서 | 주어진 글 + (A)(B)(C). 나누는 위치와 정답 번호를 문제마다 바꿉니다. |
| 자동 (무료) | 문장삽입 | 연결어·지시어로 시작하는 문장을 먼저 골라 뺍니다. |
| 자동 (무료) | 서술형 문장배열 | 문장 전체, 또는 쉼표나 문장 끝에서 끝나는 7~12단어를 `<보기>`로 섞습니다. |
| AI | 주장, 요지, 주제, 제목, 어법, 어휘, 함축적 의미, 빈칸, 요약, 한글 문장 영작, 어법 오류 고치기 | Claude가 만듭니다. |

AI 유형을 만드는 방법은 두 가지입니다.

- **Claude 화면 안에서 열었을 때**: 버튼을 누르면 Claude가 바로 만듭니다. 사용하는 사람의 Claude 사용량을 씁니다. 처음 한 번 허용을 묻습니다.
- **파일로 열었을 때**: 요청문을 복사해 [claude.ai](https://claude.ai/new) 채팅에 붙여 넣고, 답변을 다시 붙여 넣어 불러옵니다.

AI가 만든 문제는 반드시 검토한 뒤 사용하세요.

## 시험지 디자인

- A4, 2단(가운데 옅은 구분선), 머리말·꼬리말과 쪽 번호
- 문항 번호는 남색 큰 숫자, 발문은 굵은 고딕, 원문 번호는 발문 위 작은 회색 글씨
- 주어진 글·`<보기>`·요약문은 옅은 남색 배경 상자 (흑백 인쇄 시 옅은 회색)
- 영어는 모두 Times New Roman, 한글은 함초롬바탕·함초롬돋움

## 알아 둘 점

- 문장은 마침표·물음표·느낌표를 기준으로 자동으로 나눕니다. `Dr.`, `U.S.` 같은 약어는 대부분 처리하지만, 잘못 나뉘면 지문을 한 줄에 한 문장씩 쓰고 "한 줄에 한 문장씩" 칸을 체크하세요.
- HWPX는 한글 2014 이상에서 열립니다.
- 지문 보관함은 브라우저에 저장됩니다. **보관함 백업**에서 파일로 저장해 두면 다른 컴퓨터에서 불러올 수 있습니다.
- PDF는 쪽 미리보기를 그림으로 찍어 만듭니다. 글자를 선택하거나 검색할 수는 없고, 처음 저장할 때 인터넷 연결이 필요합니다.
- 만든 문제와 지문은 브라우저에만 저장되며, 다른 곳으로 보내지 않습니다.

## 개발

`src/`의 파일을 고친 뒤 하나로 합칩니다.

```bash
python variant-maker/build.py                  # index.html, dist/artifact.html 생성
node --test variant-maker/tests/core.test.js   # 테스트
```

- `src/core.js`: 문장 나누기, 자동 유형 생성, AI 요청문과 답변 읽기, HWPX·DOCX 만들기 (화면과 무관한 로직)
- `src/app.js`: 화면 동작
- `src/hwpx-template.js`: HWPX 빈 문서 틀. [python-hwpx](https://github.com/airmang/python-hwpx)(Apache-2.0)의 `Skeleton.hwpx`에 글자·문단 모양(굵게, 밑줄, 상자 등)을 추가한 것입니다. 라이선스는 `template/python-hwpx-LICENSE`에 있습니다.
- `tools/make_hwpx_template.py`: `hwpx-template.js`를 다시 만드는 스크립트
- PDF 저장에는 [html2canvas](https://html2canvas.hertzen.com/) 1.4.1(MIT)과 [jsPDF](https://github.com/parallax/jsPDF) 2.5.1(MIT)을 cdnjs에서 불러와 씁니다.
